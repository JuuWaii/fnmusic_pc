# 专辑与歌手浏览

更新：2026-09-16。

## 当前实现

- 音乐资料库新增歌曲、专辑、歌手入口。专辑和歌手列表每页 50 项，可点击条目或选择后点击“查看详情”。
- 详情显示名称和歌曲数量，歌曲独立分页获取；返回列表恢复进入详情前的页码。缺少歌曲数量时显示未知，不当作零。
- 详情歌曲复用按钮播放、双击播放和当前页队列；浏览、返回或切换类别不改变已有队列。队列来源显示专辑/歌手详情当前页。
- 搜索框始终搜索歌曲；提交搜索或清空会返回歌曲视图。刷新加载当前类别的第一页。
- 列表、详情和搜索共享曲库请求取消源；响应写回前检查取消和窗口关闭。会话变化清空浏览状态，播放请求保持独立。

## 已审查的静态契约

证据来自本机缓存的 NAS 前端 API 模块和专辑/歌手页面模块。未复制签名材料或用户数据。

| GET 路径 | 参数 | 响应消费方式 |
| --- | --- | --- |
| album/list、artist/list | page、size | data.list、data.total；条目 guid、name、可选 trackCount |
| album/detail | guid | 直接专辑对象，或 data.album 包装 |
| artist/detail | guid | 直接歌手对象 |
| track/album-detail/list | albumGUID、page、size、sort=trackNo,asc | list、total，沿用曲库曲目映射 |
| track/artist-detail/list | artistGUID、page、size | list、total，沿用曲库曲目映射 |

复用现有认证、重定向拒绝、15 秒超时和 2 MiB 响应限制。列表条数超过请求大小或 total 时拒绝，当前实例实测支持服务端分页，无需套用搜索接口的完整集合兼容规则。
