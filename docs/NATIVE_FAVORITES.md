# 原生收藏功能

更新：2026-09-22。

音乐资料库新增“收藏”入口，支持分页、刷新和当前页播放。歌曲选中后显示“收藏歌曲”或“取消收藏”；操作进行中禁用按钮，成功后更新当前行状态。收藏列表取消收藏后重新加载，当前页仅剩一首时返回上一页。浏览变化不撤销服务器写入，也不将旧页面结果写回新页面；会话变化及窗口关闭取消请求。浏览及收藏变更不替换已有播放队列。

缓存前端静态证据确认：GET `favorite-track/list` 使用 page、size；POST `favorite-track/create` 和 `favorite-track/delete` 的 JSON 均为 `{ trackGUID }`。曲库、搜索及详情行读取 isFavorite；收藏列表将返回条目标记为已收藏。

复用现有认证、超时、响应大小限制和失效会话保护。普通失败不更新本地收藏标记，也不自动重发写入；提示用户刷新核对结果，因为网络失败不证明服务器未执行。
