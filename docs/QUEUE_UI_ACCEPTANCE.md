# 队列窗口验收记录

日期：2026-09-13 至 2026-09-14。

使用 Debug `--preview-synthetic`，两首 60 秒内存合成音频，默认静音，不读取 NAS 会话。通过真实窗口按钮、双击、模式下拉框和进度条指针操作验证；不是仅调用队列领域方法。

| 场景 | 观察结果 |
| --- | --- |
| 删除当前曲目 A | 播放停止、当前曲名清空，队列保留 B |
| 从队列选择 B 并播放 | 播放 B，队列 1/1 |
| 清空并重建 | 清空后停止，再从曲库播放恢复为双曲目队列 |
| 删除非当前曲目 B | A 保持播放，进度继续前进，队列 1/1 |
| 顺序播放 | A 曲尾自动切 B；B 曲尾显示队列播放结束 |
| 列表循环 | B 曲尾自动回到 A，队列 1/2 |
| 单曲循环 | A 从 57 秒跨曲尾回到 6 秒，仍是 A；弹窗全程保持打开 |
| 单曲循环手动下一首 | 手动下一首切到 B，队列 2/2 |

修复并在 2026-09-14 新编译窗口复测：删除当前曲目后的“队列 0/1”改为“队列 1 首 · 未选择播放曲目”；无选择时禁用移除和播放，空队列禁用清空。

Debug 和 Release 均为 0 警告、0 错误；正常 Windows 用户下 23 项原生检查通过，包含 DPAPI。本次未重跑可选 FFmpeg 格式矩阵。真实 NAS 大文件、快速连续操作、触摸与网络失效仍属于后续回归范围。

随机模式（2026-09-14）：A 跳至 58 秒后自动续播 B，B 已推进至 21 秒；点击上一首返回 A，队列 1/2。两首测试曲目只能验证不立即重复与历史返回，不能代表大型队列随机分布的统计验收。
